# aws/ec2 contract discovery

Use endly_service_info with service and optional action through MCP. Or inspect the live CLI contract with `endly -s=aws/ec2 -a=<action>`. Read `service/system/cloud/aws/ec2/README.md` in a matching Endly checkout for maintained service documentation.

Available source-declared actions: getInstance, getSecurityGroups, getSubnets, getVpc, getVpcConfig.
