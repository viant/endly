# aws/iam contract discovery

Use endly_service_info with service and optional action through MCP. Or inspect the live CLI contract with `endly -s=aws/iam -a=<action>`. Read `service/system/cloud/aws/iam/README.md` in a matching Endly checkout for maintained service documentation.

Available source-declared actions: getRoleInfo, getUserInfo, recreateRole, setupRole.
