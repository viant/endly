# webdriver contract discovery

Use endly_service_info with service and optional action through MCP. Or inspect the live CLI contract with `endly -s=webdriver -a=<action>`. Read `service/testing/runner/webdriver/README.md` in a matching Endly checkout for maintained service documentation.

Available source-declared actions: call-driver, call-element, capture-clear, capture-export, capture-start, capture-status, capture-stop, close, open, run, start, stop, stop-loading.
