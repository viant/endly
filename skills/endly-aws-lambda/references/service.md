# aws/lambda contract discovery

Use endly_service_info with service and optional action through MCP. Or inspect the live CLI contract with `endly -s=aws/lambda -a=<action>`. Read `service/system/cloud/aws/lambda/README.md` in a matching Endly checkout for maintained service documentation.

Available source-declared actions: call, deploy, recreateFunction, setupPermission, setupTriggerSource.
