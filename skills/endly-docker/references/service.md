# docker contract discovery

Use endly_service_info with service and optional action through MCP. Or inspect the live CLI contract with `endly -s=docker -a=<action>`. Read `service/system/docker/README.md` in a matching Endly checkout for maintained service documentation.

Available source-declared actions: build, copy, inspect, login, logout, logs, pull, push, remove, run, start, status, stop, tag.
